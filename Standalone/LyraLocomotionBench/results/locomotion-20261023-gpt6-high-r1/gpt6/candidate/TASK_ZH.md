# Lyra 风格平地移动动画交付任务

本任务在独立目录内完成，不使用 Unreal Editor，不修改现有 UE 工程，也不要求编译或运行 UE。目标是将给定 Lyra 无武器地面移动素材组织为一份可以审查的动画资源与控制逻辑交付。

请完成平地前、后、左、右方向的走路和跑步，以及相应的起步、停步、变向 pivot 和原地转身。角色每帧接收速度、加速度、角色朝向、瞄准朝向和时间步长。请自行设计资源加工、动画图配置和控制逻辑，使它们能配合表达这些行为及行为之间的变化。资源与逻辑应适用于输入变化，不能只为一个预先写死的片段生成结果。

原始输入在 `raw/manifest.json`。清单包含 37 条地面素材目录项；其中 15 条提供 26 骨骼姿态抽样，其余只有元数据。清单中的 `availability` 和 `pose_file` 是各素材是否有抽样的依据。抽样不是完整 Manny 骨架，也不是原始 AnimBP 的运行结果。原始资源、加工结果与运行时角色的坐标约定见 `INTERFACE.md`。

有抽样的素材应实际读取并加工。只有元数据的素材应保留对原始条目的引用，提交可复用的加工配方，并标为 `deferred_missing_samples`。不能编造骨骼姿态、曲线数值、打点时间或已经执行过加工的结果。Idle 等只有元数据的资源同样不能声称已具有可播放姿态。缺少采样不妨碍提交依赖这些素材的通用配置与逻辑，但需要将依赖关系和待完成工作写清楚。

请完成以下交付：

- `src/build_assets.py`：实际的 Python 资源制作逻辑。通过约定的 CLI 读取原始清单，生成 `assets/authored_assets.json`，需要时可在该目录生成其他加工产物。
- `assets/authored_assets.json`：实际生成的资源说明、加工数据或产物引用，以及缺失输入对应的延后加工配方。
- `config/animation_graph.json`：与实现一致的动画图和配置，资源引用必须能追溯到输入清单或明确记录的加工结果。
- `src/controller.py`：实际的 Python 每帧控制逻辑，返回接口规定的播放计划、同步组设置和姿态操作描述。
- `IMPLEMENTATION.md`：简短说明制作与使用方式、关键假设、限制和未完成部分。

可以增加帮助实现的模块。保留约定的入口和输出文件。单独提交文字设计、空配置或未实现的函数不构成完成。

本次采用静态交付审查，不提供 UE 执行器、动画图解释器或姿态渲染器，也不要求你制作这些系统。控制器输出的是动画执行计划，不是最终渲染姿态。请勿将交付描述为已经在 UE 中验证、已经运行完整 AnimGraph，或已经获得姿态质量测量结果。
